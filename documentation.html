6. Multi-Company Management

Kaise kaam karta hai:

  • Header mein dropdown se company select karo
  • "+ Add" button se nayi company add karo
  • "Del" button se company delete karo (with all data)
  • Har company ka data bilkul alag Firebase mein store hota hai
  • Last selected company yaad rehti hai

7. Barcode Scanner

Supported Formats:

  • EAN-13, EAN-8
  • UPC-A, UPC-E
  • Code 128, Code 39
  • QR Code
  • ITF, Codabar

Kaise use kare:

  1. New Stock / Stock In / Stock Out tab mein jao
  2. SKU field ke paas camera icon pe click karo
  3. Camera khulega - barcode ke saamne rakho
  4. Scan hote hi SKU auto-fill ho jayega
  5. Agar item database mein hai toh product name bhi auto-fill

Note: HTTPS required hai barcode scanning ke liye (GitHub Pages pe already HTTPS hai).

11. Firebase FREE Plan (Spark) Limits

ResourceFREE LimitStatus
Database Storage1 GBEnough
Database Downloads10 GB/monthEnough
Simultaneous Connections100Enough
Writes per second1000Enough
Firebase StorageNot UsedN/A

Tips to stay within limits:

  • Images compress hoti hain (300px, 70% quality) → ~10-30KB per image
  • 1GB storage mein approximately 10,000+ items with images store ho sakte hain
  • Agar images nahi use karo toh 50,000+ items easily
  • Monthly 10GB download limit → normal use mein kabhi nahi bharta

PDF Banane ke liye:

Ctrl + P (Print) dabao → Destination mein "Save as PDF" select karo → Save!
